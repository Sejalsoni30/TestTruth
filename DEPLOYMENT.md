# TestTruth — Deployment Guide

TestTruth can be deployed in under 2 minutes using any of the following platforms.

---

## Option 1: Vercel (Frontend) + Render / Railway (Backend) — Recommended

### 1. Deploy Frontend on Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub account and select repository: `Sejalsoni30/TestTruth`.
3. Set **Root Directory** to: `frontend`
4. Set **Build Command**: `npm run build`
5. Set **Output Directory**: `dist`
6. Click **Deploy**. Vercel will automatically configure SPA client routing via `frontend/vercel.json`.

---

### 2. Deploy Backend on Render
1. Go to [dashboard.render.com](https://dashboard.render.com).
2. Click **New +** -> **Blueprint**.
3. Connect your repository `Sejalsoni30/TestTruth`.
4. Render will read `render.yaml` and provision:
   - `testtruth-backend` (Node.js API web service)
   - `testtruth-frontend` (React + Vite static web app)
5. Click **Apply**.

---

## Option 2: 1-Click Railway Deployment
1. Go to [railway.com/new](https://railway.com/new).
2. Select **Deploy from GitHub repo** -> `Sejalsoni30/TestTruth`.
3. Railway automatically detects the project using `backend/Dockerfile` or Nixpacks.
4. Set environment variable:
   - `JWT_SECRET`: your secret key (or generated by Railway)
5. Click **Deploy Now**.

---

## Option 3: Netlify Deployment
1. Go to [app.netlify.com](https://app.netlify.com).
2. Click **Add new site** -> **Import an existing project**.
3. Select `Sejalsoni30/TestTruth`.
4. Netlify will detect `netlify.toml`:
   - Base directory: `frontend`
   - Publish directory: `frontend/dist`
   - Build command: `npm run build`
5. Click **Deploy site**.

---

## Option 4: Docker & Self-Hosted VPS (DigitalOcean / AWS / GCP)
Clone the repository and run with Docker Compose:

```bash
git clone https://github.com/Sejalsoni30/TestTruth.git
cd TestTruth
docker compose up -d --build
```

The backend will be live at `http://YOUR_SERVER_IP:5000` with automated in-memory / external MongoDB and demo workspaces pre-seeded.
